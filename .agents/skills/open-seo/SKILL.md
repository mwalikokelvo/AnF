# Open SEO

Open SEO is an open-source toolchain for auditing, analyzing, and improving search engine optimization (SEO), metadata, social previews (OpenGraph, Twitter Cards), and structured data (JSON-LD schema.org).

## Core Capabilities

1. **Page & Metadata Audit**
   - Title tag length, keyword density, and truncation limits.
   - Meta description validation (character limits, readability, CTA).
   - Canonical URL enforcement and duplicate content risk detection.
   - OpenGraph (`og:title`, `og:image`, `og:description`) and Twitter Card inspection.

2. **Technical SEO & Sitemap Validation**
   - `robots.txt` rule validation (User-agent, Allow, Disallow, Sitemap references).
   - XML Sitemap syntax, schema, and response code checks.
   - Core Web Vitals readiness and mobile viewport configuration.
   - Heading hierarchy inspection (single `<h1>`, nested `<h2>`-`<h6>` flow).

3. **Structured Data Validation**
   - JSON-LD syntax checking against Schema.org types (Article, Organization, WebSite, SoftwareApplication).
   - BreadcrumbList and navigation microdata validation.
