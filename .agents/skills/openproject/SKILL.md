# OpenProject — Open-Source Project & Portfolio Management

OpenProject is an open-source management suite for tracking work packages, roadmaps, interactive Gantt timelines, resource allocation, and agile sprints.

## Core Capabilities

1. **Work Package & Issue Tracking**
   - Hierarchical task breakdown (initiatives -> epics -> user stories -> tasks -> bugs).
   - Custom fields, workflow status transitions, and role-based access control (RBAC).
   - Time tracking, cost logging, and budget monitoring per work package.

2. **Gantt Charts & Release Roadmaps**
   - Interactive timeline visualization with predecessor/successor dependency links.
   - Critical path analysis and automatic milestone rescheduling.
   - Project portfolio overview with cross-project reporting.

3. **Agile Boards & Scrum Support**
   - Backlog management, sprint planning, and velocity tracking.
   - Customizable Kanban boards with column WIP limits and swimlanes.
   - REST API v3 for programmatic work package creation, updates, and bi-directional synchronization.
