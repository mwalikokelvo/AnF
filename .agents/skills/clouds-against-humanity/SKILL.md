# Clouds Against Humanity — Cloud Architecture & Disaster Simulation

Clouds Against Humanity is a self-hostable party and tabletop simulation game designed for DevOps engineers, cloud architects, and site reliability engineers (SREs).

## Core Capabilities

1. **Architecture & Incident Simulation**
   - Scenario prompt cards representing complex cloud outages, compliance failures, DNS disasters, and security breaches.
   - Response cards detailing modern cloud patterns, Kubernetes workarounds, rollback procedures, and chaos engineering techniques.
   - Multiplayer live web interface for remote architectural review sessions.

2. **Educational & Threat Modeling Application**
   - Gamified post-mortem analysis and tabletop exercises.
   - Highlighting realistic failure modes across AWS, Azure, GCP, on-premise Kubernetes, and serverless architectures.
   - SRE training on incident triage, blast radius containment, and redundancy planning.
