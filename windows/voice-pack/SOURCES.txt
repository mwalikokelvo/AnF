JARVIS Voice Pack samples
=========================

Place the 13 reference MP3s here (filenames must match jarvis-voice-pack.ts).

Vite serves them at /voice-pack/*.mp3 in dev and copies them into dist/voice-pack/
on build. If a file is missing, JARVIS still speaks via Web Speech and synthesizes
a short Web Audio identity chirp instead of the MP3 cue.

  Burt - deep, smooth and clear.mp3
