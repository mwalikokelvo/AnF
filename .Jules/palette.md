## 2024-05-18 - Added aria-labels to main navigation icon buttons\n**Learning:** Missing aria-labels on icon-only buttons can create accessibility issues for screen readers. Using titles helps, but aria-labels provide a more explicitly defined and reliable text alternative.\n**Action:** Add aria-labels to icon-only buttons matching their titles. Also, for dynamic icon buttons like "Mute"/"Unmute" and "Send"/"Copy question and open browser", ensure the aria-labels update dynamically alongside the titles.
